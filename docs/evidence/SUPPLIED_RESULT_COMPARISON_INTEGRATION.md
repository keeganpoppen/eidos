## Outcome and demonstrated need

The [precise reproduction](IMPORT_REPRODUCTION_EXPERIMENT.md) showed that ordinary
text evidence, contexts and findings can preserve a repeatable local check. Actual
browser inspection then found the review's default comparison selected the same
finding on both sides, while authored work advertised unavailable specialist
inquiry guidance and a synthetic alternative. Baseline was 11 GETs, zero POSTs.

A cited result input now offers **Compare with this supplied result**. The action
captures the displayed result's exact context and frozen input, resolves their
original owners and stages an ordinary comparison review. Apply changes the browser
arrangement; Save retains the existing immutable composition. The applied labels
describe the supplied-input relationship. Citation establishes supply, not approval,
causality, claim validity or execution. No serialized presentation intent was added.

Both source payloads must agree with exact owner/context/artifact pins, frozen
artifact contents and manifest pins. Mutable current adoption may differ from the
historical selected review. Unknown native artifact fields participate in equality.
Missing or disagreeing originals refuse staging; the frozen copy remains readable
through provenance. Apply revalidates against the current owner views. These reads
are not one atomic server snapshot; canonical composition Save independently checks
its references. This is not continuous certification of historical source content.

Examples now live in a disclosure. RecordedExperiment remains mounted for recovery,
but clean authored-only work no longer shows unavailable native-inquiry creation.
Saved experiments, pending requests, load errors and retry remain visible. Native
eligibility and the legacy requested-policy bytes are unchanged.

## Consequence and remaining question

Values and exact dependencies. It does not measure human reorientation, answer
quality, cross-machine reproducibility or native account usefulness. The custom
reproduction bundle added convenient traversal closure; the existing projected
prompt already contains all five raw reproduction files. Export is not yet a
demonstrated missing capability. Next test whether a fresh participant can discover
the controlling evidence and choose a useful repair through existing product reads,
