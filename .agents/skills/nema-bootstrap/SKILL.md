# Reconstitute, then act

Read the root [AGENTS.md](../../../AGENTS.md) and [START_HERE.md](../../../START_HERE.md). Follow the short reading order; do not load every historical document into every agent.

Inspect HEAD, branch, working tree, current handoff, and actual tool availability. Reconcile implementation against [STATE](../../../docs/roadmap/STATE.md). The baseline already has discovery and a generic named-protocol ProcessRuntime; do not reimplement them from an older next-step paragraph.

Select a complete user-visible loop from [V1](../../../docs/roadmap/V1.md), explaining its leverage and main uncertainty. Follow [ORCHESTRATION](../../../docs/agents/ORCHESTRATION.md): bounded scouts, explicit shared contract, disjoint ownership, independent review, one integrator. Do not claim unavailable subagents ran.

Deliver a task packet, implementation/verification appropriate to the session, and a durable handoff. Distinguish aspirations, measured behavior, local simulation, and open obligations. Preserve the personal reflective-workbench destination rather than treating the most recent kernel experiment as the product.
