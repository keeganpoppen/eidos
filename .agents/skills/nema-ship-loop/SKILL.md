# Deliver the loop

Read the selected [V1 scenario](../../../docs/roadmap/V1.md), relevant [workstreams](../../../docs/roadmap/WORKSTREAMS.md), and [INTERACTION](../../../docs/vision/INTERACTION.md). State the user's input, visible action, expected result, evidence, and recovery behavior before changing code.

Agree the smallest cross-lane reference/context/task/artifact contract. Trace one real or sanitized fixture through the existing recorder, projection, context preview, worker, pending/result state, and reintegration. Reuse native Codex and the generic ProcessRuntime where appropriate; do not create a second agent loop or parallel source of truth.

Write failure tests as well as happy paths. Run Python tests, UI checks/build, and actual rendered interaction review for presentation changes. Label mock versus real-native evidence. Confirm that retries, historical views, and alternative workspaces do not duplicate live authority or external effects.

Return an integrated patch, a demonstration artifact, exact verification results, unresolved limits, and an updated [handoff](../../../docs/agents/CONTINUITY.md). A new abstraction earns acceptance through the loop it makes possible.
